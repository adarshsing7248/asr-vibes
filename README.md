# 🎬 ASR-VIBES.io – Movies & Music Discovery Platform

**ASR-VIBES.io** is a web-based entertainment discovery platform where users can explore movies and music in one place. Discover trending movies, search for your favourite films, watch trailers, create a personal watchlist, and explore popular songs with audio previews.

Built with HTML, CSS, JavaScript, and TMDB API.

---

## 🌟 Features

### 🎬 Movie Discovery
- Explore Trending Movies.
- Browse Popular Movies.
- Discover Now Playing Movies.
- Explore Upcoming Movies.
- View Top Rated Movies.
- Search for movies by title.

### 🎥 Movie Details
- View movie posters.
- Check release dates and ratings.
- Explore movie genres and runtime.
- Read movie descriptions.
- Watch movie trailers through YouTube integration.
- Add movies to your personal Watchlist.

### 🎵 Music Discovery
- Explore Popular Songs.
- Discover Top Songs and New Music.
- Browse songs and artists.
- Listen to 30-second song previews.

### ⚡ Additional Features
- All, Movies, and Music category filters.
- Functional search functionality.
- Dark Mode and Light Mode.
- Interactive navigation menu.
- Personal Watchlist functionality.

---

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and responsive UI.
- **JavaScript** – Functionality and interactivity.
- **TMDB API** – Movie information, posters, ratings, and details.
- **YouTube Integration** – Movie trailer playback.

## 🎯 Project Purpose

The main purpose of this project was to build an interactive entertainment platform and gain practical experience in frontend development, API integration, dynamic data fetching, search functionality, and user interface design.
